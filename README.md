## 박태현

한양대 ERICA에서 데이터인텔리전스를 전공하고, 컴퓨터학부를 다중전공하고 있어요.
사람들이 실제로 돈 내고 쓸 만한 서비스를 직접 만들어 보고 싶어서 이것저것 만들어 보는 중이에요.

지금은 [Cramit](https://github.com/cramit-service/CRAMIT-FE)에서 프론트엔드를 맡고 있어요.
강의 녹음이랑 강의자료를 맞춰서 정리해 주는 학습 서비스예요. ([데모](https://cramit-fe.vercel.app))

전에는 인테리어 업체용 시안 생성 도구를 만들다가 접었어요.
이미지 생성 비용에 비해 실제 계약까지 가는 손님이 적어서 남는 게 없는 구조였어요.

관광데이터 공모전에서는 [지꾸](https://github.com/nuyh-99/ji-kku-frontend)의 PM과 프론트엔드를 했어요.

겨울방학부터 PANDA Lab에서 학부연구생으로 AI 에이전트를 공부할 예정이에요.
